# Birdeye

Birdeye is an AI-powered customer experience and reputation management platform for multi-location brands. Its REST API enables developers to manage online reviews across 200+ sites, send surveys, respond to customer messages, automate review request workflows, and track reputation metrics including ratings, sentiment trends, and NPS scores.
